# Simulación de una caja de agua

La caja de agua pura es un sistema de control útil para validar la instalación de GROMACS y estudiar relaciones entre parámetros microscópicos y propiedades termodinámicas del líquido.

El [laboratorio de agua pura](proteina-agua.md#laboratorio-de-agua-pura-condiciones-y-propiedades-fisicas) desarrolla dos modelos (TIP4P-Ew y SPC/E), variaciones de temperatura y presión, producción NVT/NPT, tamaño finito y cálculo de densidad, difusión, distribución radial, compresibilidad, expansión térmica y capacidad calorífica.

Los [scripts reproducibles](https://github.com/juanjosecas/manual-gromacs/tree/main/examples/water-box) crean cada sistema y ejecutan todas las etapas sin modificar archivos manualmente.

Este protocolo estudia **agua sin proteína**. Para estudiar una proteína solvata, consultar [Dinámica de una proteína en agua](proteina-agua.md).
